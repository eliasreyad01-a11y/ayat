# AYAT — آيات

Android TV Quran player (WebView app). Verse-by-verse recitation from everyayah.com.

- `app/src/main/assets/index.html` — the whole UI
- `app/src/main/assets/bg/` — bundled backgrounds (`madina.jpg`, `night.jpg`)
- `.github/workflows/build.yml` — builds the APK on every push and publishes it to the `latest` release
- `app/ayat.keystore` — fixed signing key so new builds install over old ones

Download: Releases → `latest` → `AYAT.apk`
